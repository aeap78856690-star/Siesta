# Siesta

Siesta es un asistente de IA para Android diseñado para funcionar con:
- chat escrito
- voz
- modo online
- modo offline
- modo automático
- memoria opcional
- autenticación por huella
- permisos por usuario
- multiidioma

## Objetivo

Tener una IA personal ligera que funcione con Internet y, cuando sea posible, sin Internet.

## Funciones

- Chat escrito
- Botón para hablarle
- Respuestas mediante voz
- Modo Online
- Modo Offline
- Modo Automático
- Memoria opcional
- Ver memoria
- Borrar memoria
- Cambiar de idioma
- Bajo consumo de batería
- Bajo calentamiento
- Sin escucha permanente
- Sin activación por voz remota

## Idiomas

- Español
- Inglés
- Japonés
- Ruso

## Seguridad y usuarios

Siesta reconoce usuarios por huella digital.

Permisos por usuario:
- Tú: acceso total
- Novia: acceso total
- Prima: cámara, galería, idioma, ajustes básicos
- Prima: bloqueada en Siesta, Xender y memoria del teléfono

Si intenta entrar a funciones no autorizadas:
- se bloquea
- muestra "No tienes acceso a esto"
- vuelve a la pantalla anterior

## Requisitos

- Android SDK 34+
- Kotlin
- Gradle 8.x
- AndroidIDE o Android Studio

## Cómo compilar

1. Abrir el proyecto en AndroidIDE o Android Studio
2. Sincronizar Gradle
3. Ejecutar en emulador o dispositivo real
4. Registrar huellas
5. Probar online/offline
6. Revisar el idioma y el modo automático
